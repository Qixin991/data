# 出口目的地联动与出口下行风险预测

## 项目简介

本项目研究一个核心问题：

在出口集中度、单市场风险和宏观信息之外，出口目的地市场之间的联动，能否为出口下行风险提供额外的预测信息？

项目主要基于 BACI 双边贸易数据开展。

当前研究不预设复杂模型一定更优，而是按照：

**强基准 -> 信息增量 -> 来源分解 -> 稳定性检验**

的路线逐步推进。

目前已完成开发期实验和多组诊断实验，最终测试集仍保持封存。

---

## 1. 研究任务

以“出口国 - 产品 - 年份”为主要预测单位。

使用历史出口结构、目的地风险、市场关系和宏观信息，预测下一期是否发生显著出口下行。

当前研究重点包括：

- 出口集中度之外是否存在额外风险信息；
- 单市场风险和跨市场联动分别贡献多少；
- 复杂图模型是否真的优于简单信息汇总；
- 当前观察到的增量是否能够跨年份稳定存在。

---

## 2. 研究路线

```text

        |
        v

        |

        |

````

研究过程中保留正结果、负结果和不确定结果，不根据单次最优指标反复搜索参数。

## 3. 当前主要发现

### 3.1 复杂图模型暂未表现出稳定优势

前期实验表明，市场间关系信息可能具有预测价值。

但更复杂的图模型，目前没有显示出相对于简单汇总模型的稳定优势。

因此，当前研究重点已经从：

**“如何设计更复杂的图模型？”**

转向：

**“市场联动信息本身是否真的具有独立预测价值？”**

---

### 3.2 共同市场因素的定义会影响结果

共同因素诊断中，不同定义产生了明显不同的验证结果。

三种子平均验证 AP：

* 不加入共同因素

  * 不含关系指标：0.4288
  * 含关系指标：0.4391

* 原简单平均共同因素

  * 不含关系指标：0.4229
  * 含关系指标：0.4226

* 市场总额共同因素

  * 不含关系指标：0.4306
  * 含关系指标：0.4370

市场总额口径明显优于原简单平均口径，但并未超过所有对照。

这说明：

**共同市场变化如何被控制，会直接影响对关系信息增量的判断。**

---

### 3.3 控制单市场风险后，联动仍存在增量线索

最新实验进一步把原有“关系指标”拆分为两部分：

1. 单市场风险与数据覆盖信息；
2. 真正的跨市场联动信息。

三种子平均验证 AP：

* 不加入共同因素

  * A：基础模型 = 0.4288
  * B：加入单市场风险与覆盖 = 0.4292
  * C：进一步加入跨市场联动 = 0.4357

* 市场总额共同因素

  * A：基础模型 = 0.4306
  * B：加入单市场风险与覆盖 = 0.4326
  * C：进一步加入跨市场联动 = 0.4356

其中：

* 不加入共同因素时，C - B = +0.0065 AP
* 市场总额口径下，C - B = +0.0030 AP

但两种条件下的不确定性区间仍包含 0。

因此，目前更准确的结论是：

**控制单市场风险和覆盖信息后，跨市场联动仍表现出正向预测增量线索，但现有证据尚不足以确认这一增量具有稳定性。**

---

## 4. 当前研究判断

目前证据支持继续研究“市场联动是否具有条件预测增量”，但尚不足以作出更强结论。

当前能够确定的是：

* 不能把现有改善简单归因于图模型；
* 不能把关系指标的改善简单归因于单市场波动；
* 不能因为部分实验 AP 上升，就认定联动信息已经稳定有效；
* 最终测试集尚未使用。

下一阶段重点是：

**检验这些增量能否跨年份稳定存在，以及它在什么条件下出现或消失。**

## 6. 数据与实验原则

本项目主要使用：

* BACI 双边贸易数据；
* 宏观经济数据；
* 根据历史出口目的地结构构造的风险和关系特征。

当前实验遵循以下原则：

* 开发验证与最终测试严格分离；
* 最终测试集在研究方案确定前保持封存；
* 固定参数的诊断实验不因结果不理想而重新搜索参数；
* 保留负结果和不确定结果；
* 大型原始数据、模型文件及逐样本预测不纳入 Git 仓库。
