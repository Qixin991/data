# 字段与单位

| 字段 | 含义及计算 |
|---|---|
| t | 特征年份，标签使用下一年t+1 |
| i / j | BACI出口经济体 / 进口经济体数字代码，不能直接当ISO代码 |
| hs4 | 原始HS92六位产品代码前四位，限HS84 |
| v / export_value | 双边 / 产品总出口额，千现价美元 |
| log_export | log(1+export_value)，自然对数 |
| destinations | 具有正贸易流的目的地数量 |
| hhi | 全部目的地份额平方和，值越高集中度越高 |
| top_share | 最大目的地出口份额 |
| growth | export_value(t)/export_value(t−1)−1，小数比例；相邻年缺失则未知 |
| growth_mean3 | 最近三年增长率的均值，至少两个有效观测 |
| growth_std3 | 最近三年增长率的样本标准差，至少两个有效观测 |
| dest_log_gdp | 在GDP已知且为正的目的地中，按出口份额加权平均log(1+GDP美元)，不是总GDP的对数 |
| dest_gdp_growth_pct | 在可观测目的地中，按出口份额加权的实际GDP年度增长，单位百分点 |
| dest_inflation_pct | 在可观测目的地中，按出口份额加权的消费者价格通胀，单位百分点 |
| *_coverage | 该宏观指标已知的目的地占总出口的份额，0至1 |
| next_export | 下一年产品总出口，缺失不补零；仅用于标签和审计，不能作为特征 |
| next_growth | next_export/export_value−1；仅用于标签和审计 |
| risk | next_growth≤−0.2时为1，否则0；next_growth缺失则未知 |
| eligible | 基期export_value≥1000且标签已知 |
| split | train、validation、calibration_unused、test或history_or_unlabeled |
| probability | 分类模型对risk=1的预测概率，未校准 |
| prediction_0.5 | probability≥0.5时预测为1 |
| cluster | 聚类编号，没有天然顺序；DBSCAN中−1表示噪声候选 |
| AP | Average Precision，越高越好，随机排序参考风险发生率 |
| ROC_AUC | ROC曲线面积，越高越好 |
| Brier | 概率与0/1标签的均方误差，越低越好 |

模型填补器还会为训练期有缺失的特征增加 `missingindicator_` 前缀的指示列。逻辑回归系数对应标准化后的特征，决策树/随机森林重要性为不纯度下降重要性，不是因果贡献。增长率的小数单位和宏观变量的百分点单位不同，已经明确保留，不混为同一口径。
