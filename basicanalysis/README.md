# 贸易数据课程基础分析

依据本目录上一级的《数据挖掘课程教学大纲.docx》选择方法，读取“新建文件夹”的BACI贸易数据和三份WDI宏观指标。结果用于课程方法练习和后续研究基线，不包含REPAIR创新模型的完成声明。

## 从哪里开始

先阅读 `分析总览.md`，再进入所需方法文件夹查看 `分析说明.md`、结果CSV和PNG图。所有数值来自实际运行，CSV使用UTF-8 BOM，适合Excel打开。产品代码应以文本导入，金额单位除图中另行标注外均为千现价美元。

| 文件夹 | 大纲对应 | 分析内容 |
|---|---|---|
| 00_数据预处理与描述统计 | 第二、三章 | 数据审计、HS6聚合HS4、宏观合并、缺失审计、描述统计与相关性 |
| 01_OLAP多维聚合 | 第四、五章 | 事实表、上卷、切片、下钻、透视 |
| 02_标准化_PCA_KMeans | 第三、十、十一章 | 截尾、填补、标准化、PCA、K-means串行流程 |
| 03_DBSCAN密度聚类 | 第十、十一章 | 标准化后密度聚类、噪声候选、参数敏感性 |
| 04_离散化_Apriori关联规则 | 第三、六章 | 训练期离散化、频繁项集、下行风险规则串行流程 |
| 05_决策树分类 | 第八章 | 可解释树规则、时间外分类评价 |
| 06_逻辑回归分类 | 第八章线性分类器 | 标准化、逻辑回归、时间外分类评价 |
| 07_随机森林分类 | 第八章集成分类 | 随机森林、重要性、时间外分类评价 |

公共预处理只运行一次，各分支读取同一结果。独立方法分文件夹；具有依赖关系的步骤归并在同一文件夹。逻辑回归是大纲“线性分类器”的具体实现。没有为了覆盖大纲而强行加入神经网络、SVM、序列模式或频繁子图，也没有把普通聚合说成BUC算法。

## 运行

安装依赖：`python -m pip install -r requirements.txt`。

在本目录执行 `python run_all.py`；已完成预处理时执行 `python run_all.py --skip-preparation`。各方法也可独立运行对应 `run.py`。默认读取同级相邻“新建文件夹”，无需修改绝对路径。完整扫描约9GB未压缩数据，耗时取决于设备；代码直接读取ZIP，不展开全部原始文件。年度缓存只保存HS84聚合值，重新运行会复用缓存。更换原始版本须重新建立输出目录，避免旧缓存混用。

分类训练年份2007—2015，验证2016—2018，测试2021—2023。2019—2020保留、不用于本次校准。国家选择只看1995—2006。阈值下降20%、最低100万美元及行业HS84沿用研究方案。所有预测特征最多使用t年数据；标签来自t+1年。没有2025贸易数据，所以2024仅做无监督截面描述，不能纳入有标签评估。

## 边界

当前基础分类只研究次年仍观测到正出口的持续出口样本；未知缺失和完全退出不直接标为风险，可能低估退出类风险。统一发布版本的历史修订数据不等同于真实实时信息。聚类、规则和重要性描述统计关联，不支持因果推断。原始研究方案要求的图关系、目的地剔除本国进口和创新模型消融尚不在本次范围内。课程大纲最终项目另要求近三年论文任务实现及综述，本分析包本身不代表已完成那两项任务。
